# 干支系统 / GanZhi System

干支是中国传统历法的核心概念，由天干（10个）和地支（12个）组合而成，形成60个不同的组合，称为六十甲子。

## 天干 Heavenly Stems

### 定义
```moonbit
// 天干名称
["甲", "乙", "丙", "丁", "戊", "己", "庚", "辛", "壬", "癸"]
```

### 核心类型
- **HeavenStem** (`heaven_stem.mbt`) - 天干类型，基于 `LoopTyme` 实现

### 主要属性
| 属性 | 说明 | 示例 |
|------|------|------|
| 五行 | 木火土金水 | 甲→木, 乙→木, 丙→火 |
| 阴阳 | 阳干/阴干 | 甲→阳, 乙→阴 |
| 方位 | 东南西北中 | 甲→东 |
| 十神 | 生我/我生/克我/我克/同我 | 见下方 |

### 十神 Ten Stars
十神描述天干之间的生克关系：
- 正印、偏印（生我者）
- 伤官、食神（我生者）
- 正官、七杀（克我者）
- 正财、偏财（我克者）
- 比肩、劫财（同我者）

```moonbit
let stem_a = HeavenStem::from_name("甲").unwrap()
let stem_b = HeavenStem::from_name("乙").unwrap()
let ten_star = stem_a.get_ten_star(stem_b)  // 甲对乙的关系
```

## 地支 Earthly Branches

### 定义
```moonbit
// 地支名称
["子", "丑", "寅", "卯", "辰", "巳", "午", "未", "申", "酉", "戌", "亥"]
```

### 核心类型
- **EarthBranch** (`earth_branch.mbt`) - 地支类型

### 主要属性
| 属性 | 说明 | 示例 |
|------|------|------|
| 五行 | 含本气、中气、余气 | 子→水 |
| 阴阳 | 阳支/阴支 | 子→阳, 丑→阴 |
| 藏干 | 本气/中气/余气 | 辰藏戊(本)、乙(中)、癸(余) |
| 生肖 | 对应生肖 | 子→鼠 |

### 地支藏干
每个地支藏有1-3个天干：
| 地支 | 本气 | 中气 | 余气 |
|------|------|------|------|
| 子 | 癸 | - | - |
| 丑 | 己 | 癸 | 辛 |
| 寅 | 甲 | 丙 | 戊 |
| 卯 | 乙 | - | - |
| 辰 | 戊 | 乙 | 癸 |
| 巳 | 丙 | 庚 | 戊 |
| 午 | 丁 | 己 | - |
| 未 | 己 | 丁 | 乙 |
| 申 | 庚 | 壬 | 戊 |
| 酉 | 辛 | - | - |
| 戌 | 戊 | 辛 | 丁 |
| 亥 | 壬 | 甲 | - |

```moonbit
let zi = EarthBranch::from_name("子").unwrap()
let main = zi.get_hide_heaven_stem_main()    // 本气
let middle = zi.get_hide_heaven_stem_middle() // 中气（可能有）
let residual = zi.get_hide_heaven_stem_residual() // 余气（可能有）
```

## 六十甲子 Sixty Cycles

### 定义
由天干和地支按固定规则配对形成60个组合：
```
甲子、乙丑、丙寅、丁卯、...、癸亥
```

### 核心类型
- **SixtyCycle** (`sixty_cycle.mbt`) - 六十甲子类型

### 用途
- 纪年（60年一循环）
- 纪日（60日一循环）
- 纪月（60月一循环）
- 纪时（60时一循环）

```moonbit
let jiazi = SixtyCycle::from_name("甲子").unwrap()
let next = jiazi.next(1)  // 乙丑
let prev = jiazi.next(-1) // 癸亥
```

### 六十甲子与干支转换
```moonbit
// 从六十甲子获取天干地支
let cycle = SixtyCycle::from_name("甲子").unwrap()
let hs = cycle.get_heaven_stem()   // 甲
let eb = cycle.get_earth_branch()  // 子

// 从干支构造六十甲子
let hs = HeavenStem::from_name("甲").unwrap()
let eb = EarthBranch::from_name("子").unwrap()
let cycle = SixtyCycle::from_heaven_stem_and_earth_branch(hs, eb)
```

## 三柱 Three Pillars

八字的前三柱（年、月、日）：
```moonbit
// 从名称构造
let three_pillars = ThreePillars::new("甲子", "乙丑", "丙寅").unwrap()

// 从六十甲子构造
let three_pillars = ThreePillars::from_sixty_cycle(year, month, day)

// 访问各柱
let year = three_pillars.get_year()   // 甲子
let month = three_pillars.get_month() // 乙丑
let day = three_pillars.get_day()     // 丙寅
```

## 地支关系

### 六冲（六冲）
地支六冲表示对立关系：子午冲、丑未冲、寅申冲、辰戌冲、卯酉冲、巳亥冲。

```moonbit
let zi = EarthBranch::from_name("子").unwrap()
let wu = zi.get_opposite()  // 午
```

### 六合
地支六合表示和谐关系：子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合。

```moonbit
let zi = EarthBranch::from_name("子").unwrap()
let chou = zi.get_combine()  // 丑
```

### 六害（六穿）
地支六害表示互相损害的关系：子未害、丑午害、寅巳害、卯辰害、申亥害、酉戌害。

```moonbit
let zi = EarthBranch::from_name("子").unwrap()
let wei = zi.get_harm()  // 未
```

### 六破（v0.2.3 新增）
地支六破表示破坏关系：子酉破、丑辰破、寅亥破、卯午破、巳申破、戌未破。六破是对称的。

```moonbit
let zi = EarthBranch::from_name("子").unwrap()
let you = zi.get_po()  // 酉
```

### 三刑
地支三刑包括：
- 无恩之刑：寅巳申
- 恃势之刑：丑戌未
- 自刑：辰辰、午午、酉酉、亥亥

```moonbit
let zi = EarthBranch::from_name("子").unwrap()
let xings = zi.get_xing()  // [卯]
```

### 三合局（v0.2.3 新增）
地支三合局表示三方汇聚成局：
- 申子辰合水局
- 寅午戌合火局
- 巳酉丑合金局
- 亥卯未合木局

```moonbit
let zi = EarthBranch::from_name("子").unwrap()
let element = zi.get_san_he_element()  // 水
```

### 三会方局（v0.2.3 新增）
地支三会方局表示方位汇聚：
- 亥子丑会北方水
- 寅卯辰会东方木
- 巳午未会南方火
- 申酉戌会西方金

```moonbit
let zi = EarthBranch::from_name("子").unwrap()
let element = zi.get_san_hui_element()   // 水
let direction = zi.get_san_hui_direction()  // 北
```

### 暗合
地支暗合表示隐秘和谐关系：寅丑、卯申、午亥。

```moonbit
let yin = EarthBranch::from_name("寅").unwrap()
let chou = yin.get_an_he()  // Some(丑)
```

### 绝
地支绝表示气数将尽：子巳、亥午、寅酉、卯申。土支不参与。

```moonbit
let zi = EarthBranch::from_name("子").unwrap()
let jue = zi.get_jue()  // Some(巳)
```

## 应用场景

### 八字排盘
```moonbit
import tyme

// 设置八字提供者
eight_char_provider = DefaultEightCharProvider::{}

// 获取农历时辰
let lunar_hour = LunarHour::from_solar_time(solar_time).unwrap()

// 计算八字
let eight_char = eight_char_provider.get_eight_char(lunar_hour)
println(eight_char.get_year().to_string())   // 年柱
println(eight_char.get_month().to_string())  // 月柱
println(eight_char.get_day().to_string())    // 日柱
println(eight_char.get_hour().to_string())   // 时柱
```

### 胎元胎息
```moonbit
let eight_char = /* ... */

let fetal_breath = eight_char.get_fetal_breath()    // 胎息

```


## 注意事项

1. **索引从0开始**：天干索引0-9，地支索引0-11，六十甲子索引0-59
2. **负数索引**：支持负数推移，自动处理循环（如 `next(-1)` 从甲子到癸亥）
3. **真太阳时**：八字计算需要考虑真太阳时修正
4. **地支关系扩展**：v0.2.3 新增六破、三合局、三会方局计算方法
