# 干支系统 / GanZhi System

干支是中国传统历法的核心概念，由天干（10个）和地支（12个）组合而成，形成60个不同的组合，称为六十甲子。

## 天干 Heavenly Stems

### 定义
```moonbit
// 天干名称
["甲", "乙", "丙", "丁", "戊", "己", "庚", "辛", "壬", "癸"]
```

### 核心类型
- **HeavenStem** (`heaven_stem.mbt`) - 天干类型，基于 `LoopTyme` 实现

### 主要属性
| 属性 | 说明 | 示例 |
|------|------|------|
| 五行 | 木火土金水 | 甲→木, 乙→木, 丙→火 |
| 阴阳 | 阳干/阴干 | 甲→阳, 乙→阴 |
| 方位 | 东南西北中 | 甲→东 |
| 十神 | 生我/我生/克我/我克/同我 | 见下方 |

### 十神 Ten Stars
十神描述天干之间的生克关系：
- 正印、偏印（生我者）
- 伤官、食神（我生者）
- 正官、七杀（克我者）
- 正财、偏财（我克者）
- 比肩、劫财（同我者）

```moonbit
let stem_a = HeavenStem::from_name("甲").unwrap()
let stem_b = HeavenStem::from_name("乙").unwrap()
let ten_star = stem_a.get_ten_star(stem_b)  // 甲对乙的关系
```

## 地支 Earthly Branches

### 定义
```moonbit
// 地支名称
["子", "丑", "寅", "卯", "辰", "巳", "午", "未", "申", "酉", "戌", "亥"]
```

### 核心类型
- **EarthBranch** (`earth_branch.mbt`) - 地支类型

### 主要属性
| 属性 | 说明 | 示例 |
|------|------|------|
| 五行 | 含本气、中气、余气 | 子→水 |
| 阴阳 | 阳支/阴支 | 子→阳, 丑→阴 |
| 藏干 | 本气/中气/余气 | 辰藏戊(本)、乙(中)、癸(余) |
| 生肖 | 对应生肖 | 子→鼠 |
| 方位 | 对应方位 | 子→北 |
| 六破 | 地支相破关系 | 子酉破、丑辰破 |
| 三合局 | 三合局五行 | 申子辰合水局 |
| 三会方 | 三会方局五行与方位 | 亥子丑会北方水 |

### 地支藏干
每个地支藏有1-3个天干：
| 地支 | 本气 | 中气 | 余气 |
|------|------|------|------|
| 子 | 癸 | - | - |
| 丑 | 己 | 癸 | 辛 |
| 寅 | 甲 | 丙 | 戊 |
| 卯 | 乙 | - | - |
| 辰 | 戊 | 乙 | 癸 |
| 巳 | 丙 | 庚 | 戊 |
| 午 | 丁 | 己 | - |
| 未 | 己 | 丁 | 乙 |
| 申 | 庚 | 壬 | 戊 |
| 酉 | 辛 | - | - |
| 戌 | 戊 | 辛 | 丁 |
| 亥 | 壬 | 甲 | - |

```moonbit
let zi = EarthBranch::from_name("子").unwrap()
let main = zi.get_hide_heaven_stem_main()    // 本气
let middle = zi.get_hide_heaven_stem_middle() // 中气（可能有）
let residual = zi.get_hide_heaven_stem_residual() // 余气（可能有）
```

### 地支六破
六破表示地支间的破坏关系，具有对称性：
| 破局 | 对应关系 |
|------|----------|
| 子酉破 | 子与酉相破 |
| 丑辰破 | 丑与辰相破 |
| 寅亥破 | 寅与亥相破 |
| 卯午破 | 卯与午相破 |
| 巳申破 | 巳与申相破 |
| 戌未破 | 戌与未相破 |

```moonbit
let zi = EarthBranch::from_name("子").unwrap()
let po = zi.get_po()  // 返回酉
```

### 地支三合局
三合局指三个地支组合形成的五行局：
| 三合局 | 组成 | 五行 |
|--------|------|------|
| 申子辰 | 申+子+辰 | 水局 |
| 寅午戌 | 寅+午+戌 | 火局 |
| 巳酉丑 | 巳+酉+丑 | 金局 |
| 亥卯未 | 亥+卯+未 | 木局 |

```moonbit
let shen = EarthBranch::from_name("申").unwrap()
let element = shen.get_san_he_element()  // 返回水
```

### 地支三会方
三会方指三个地支组合形成的方位局：
| 三会方 | 组成 | 五行 | 方位 |
|--------|------|------|------|
| 亥子丑 | 亥+子+丑 | 水 | 北 |
| 寅卯辰 | 寅+卯+辰 | 木 | 东 |
| 巳午未 | 巳+午+未 | 火 | 南 |
| 申酉戌 | 申+酉+戌 | 金 | 西 |

```moonbit
let hai = EarthBranch::from_name("亥").unwrap()
let element = hai.get_san_hui_element()  // 返回水
let direction = hai.get_san_hui_direction()  // 返回北
```

## 六十甲子 Sixty Cycles

### 定义
由天干和地支按固定规则配对形成60个组合：
```
甲子、乙丑、丙寅、丁卯、...、癸亥
```

### 核心类型
- **SixtyCycle** (`sixty_cycle.mbt`) - 六十甲子类型

### 用途
- 纪年（60年一循环）
- 纪日（60日一循环）
- 纪月（60月一循环）
- 纪时（60时一循环）

```moonbit
let jiazi = SixtyCycle::from_name("甲子").unwrap()
let next = jiazi.next(1)  // 乙丑
let prev = jiazi.next(-1) // 癸亥
```

### 六十甲子与干支转换
```moonbit
// 从六十甲子获取天干地支
let cycle = SixtyCycle::from_name("甲子").unwrap()
let hs = cycle.get_heaven_stem()   // 甲
let eb = cycle.get_earth_branch()  // 子

// 从干支构造六十甲子
let hs = HeavenStem::from_name("甲").unwrap()
let eb = EarthBranch::from_name("子").unwrap()
let cycle = SixtyCycle::from_heaven_stem_and_earth_branch(hs, eb)
```

## 三柱 Three Pillars

八字的前三柱（年、月、日）：
```moonbit
// 从名称构造
let three_pillars = ThreePillars::new("甲子", "乙丑", "丙寅").unwrap()

// 从六十甲子构造
let three_pillars = ThreePillars::from_sixty_cycle(year, month, day)

// 访问各柱
let year = three_pillars.get_year()   // 甲子
let month = three_pillars.get_month() // 乙丑
let day = three_pillars.get_day()     // 丙寅
```

## 注意事项

1. **索引从0开始**：天干索引0-9，地支索引0-11，六十甲子索引0-59
2. **负数索引**：支持负数推移，自动处理循环（如 `next(-1)` 从甲子到癸亥）
3. **真太阳时**：八字计算需要考虑真太阳时修正
4. **六破/三合/三会**：v0.2.3新增功能，`get_po()` 返回相破地支，`get_san_he_element()` 返回三合局五行，`get_san_hui_element()`/`get_san_hui_direction()` 返回三会方五行与方位
