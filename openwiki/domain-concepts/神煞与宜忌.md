# 神煞与宜忌 / Gods and Taboos

神煞和宜忌是中国传统择日学的核心内容，用于判断日期的吉凶。

## 神煞 Gods

### 概述
神煞共有约130种，分为**吉神**（0-59）和**凶神**（60-129）。

## 宜忌 Taboos

### 概述
宜忌记录了每日适合和不适合做的事情，共约100种事项。

### 主要类别
| 类别 | 事项示例 |
|------|----------|
| 祭祀 | 祭祀、祈福、求嗣、开光 |
| 婚嫁 | 嫁娶、订婚、纳采、问名 |
| 动土 | 修造、动土、上梁、竖柱 |
| 安葬 | 安葬、立碑、成服、除服 |
| 出行 | 出行、移徙、入宅 |
| 开业 | 开市、纳财、求财 |
| 其他 | 理发、探病、针灸、治病 |

## 使用示例

### 查询某天宜忌
```moonbit
import tyme

let solar_day = SolarDay::from_ymd(2024, 1, 1).unwrap()
let taboo = Taboo::get_day_taboo(solar_day).unwrap()

for item in taboo {
  println(item.to_string())
}
```

### 检查某事是否适宜
```moonbit
let solar_day = SolarDay::from_ymd(2024, 1, 1).unwrap()
let is_favorable = Taboo::is_favorable(solar_day, "嫁娶")
let is_unfavorable = Taboo::is_unfavorable(solar_day, "动土")
```

### 神煞查询
```moonbit
// 查询某日的神煞

let day_cycle = /* 日柱 */
let gods = God::get_day_gods(month_cycle, day_cycle).unwrap()

  } else {
```

## 注意事项

1. **数据编码**：神煞和宜忌数据以编码字符串形式存储，需要解析
2. **农历依赖**：部分宜忌计算需要农历日期
3. **真太阳时**：八字相关的宜忌需要考虑真太阳时
