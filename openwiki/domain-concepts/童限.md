# 童限 / Child Limit

童限是八字命理中用于计算儿童起运年龄的方法，根据出生时间与最近节令的时间差来计算。

## 核心概念

### 童限定义
童限指儿童从出生到开始行运的时间间隔，以年、月、日、时、分表示。

### 计算公式
童限 = |出生时间 - 最近节令时间| × 换算系数

## 提供者接口

```moonbit
pub trait IChildLimitProvider {
  get_info(Self, SolarTime, SolarTerm) -> ChildLimitInfo
}
```

## 实现方案

### 1. 默认方案 DefaultChildLimitProvider

**精度**：秒级

**换算关系**：
- 3天 = 1年
- 1天 = 4月（21600秒=1月）
- 1时 = 5天（720秒/天）
- 1分 = 2时（30秒/时）
- 1秒 = 2分

### 2. 中国95方案 China95ChildLimitProvider

**精度**：分钟级

**换算关系**：
- 3天 = 4320分钟 = 1年
- 1月 = 360分钟
- 1天 = 12分钟
- 1时 = 2分钟

### 3. 农历派系1 LunarSect1ChildLimitProvider

按天数和时辰数计算：3天1年，1天4月，1时辰10天。

### 4. 农历派系2 LunarSect2ChildLimitProvider

按分钟数计算，与 China95 方案类似。

## 童限信息结构

```moonbit
pub struct ChildLimitInfo {
  // 起运时间
  start_time: SolarTime,
  // 起运年龄（年、月、日、时、分）
  year: Int,
  month: Int,
  day: Int,
  hour: Int,
  minute: Int,
}
```

## 大运与童限

`ChildLimit` 类型包含起运信息，并可直接获取大运：

```moonbit
let child_limit = ChildLimit::from_solar_time(birth_time, gender)

// 起运大运（第0步）
let start_decade = child_limit.get_start_decade_fortune()

// 当前大运
let current_decade = child_limit.get_decade_fortune()

// 小运
let start_fortune = child_limit.get_start_fortune()
```

`DecadeFortune`（大运）结构：
- 每10年一步
- 支持 `Tyme` trait（推移操作）
- 可获取开始/结束年龄、干支、小运

## 使用示例

### 基本用法
```moonbit
import tyme

// 选择提供者
let provider: &IChildLimitProvider = DefaultChildLimitProvider::{}

// 计算童限
let birth_time = SolarTime::new(10, 30, 0)  // 上午10:30
let term = SolarTerm::from_name(2024, "立春").unwrap()

let info = provider.get_info(birth_time, term)
println("起运年龄: " + info.year.to_string() + "年" 
        + info.month.to_string() + "月" 
        + info.day.to_string() + "日")
```

## 注意事项

1. **节令选择**：
   - 阳日阳时：顺推至下一个节
   - 阴日阴时：逆推至上一个节
   - 阳日阴时/阴日阳时：需要根据具体规则判断

2. **精度差异**：
   - Default 方案使用秒级精度
   - China95/LunarSect2 方案使用分钟级精度
   - LunarSect1 方案使用时辰级精度

3. **真太阳时**：建议使用真太阳时进行计算
