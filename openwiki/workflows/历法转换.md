# 历法转换工作流 / Calendar Conversion Workflow

本库支持多种历法之间的转换，包括公历、农历、伊斯兰历等。

## 支持的历法

| 历法 | 类型 | 说明 |
|------|------|------|
| 公历 | SolarDay/SolarMonth/SolarYear | 国际通用格里高利历 |
| 农历 | LunarDay/LunarMonth/LunarYear | 中国传统农历 |
| 伊斯兰历 | HijriDay/HijriMonth/HijriYear | 伊斯兰教历法 |

## 公历 ↔ 农历

### 公历转农历
```moonbit
import tyme

// 公历日期
let solar_day = SolarDay::from_ymd(2024, 1, 15).unwrap()

// 转换为农历
let lunar_day = LunarDay::from_solar_day(solar_day).unwrap()
println(lunar_day.to_string())  // 输出农历日期
```

### 农历转公历
```moonbit
// 农历年月日
let lunar_year = LunarYear::from_year(2024).unwrap()
let lunar_month = LunarMonth::from_ym(2024, 1).unwrap()  // 正月
let lunar_day = LunarDay::from_ldy(lunar_month, 15).unwrap()

// 转换为公历
let solar_day = lunar_day.to_solar_day().unwrap()
println(solar_day.to_string())  // 输出: 2024年2月24日
```

### 闰月处理
```moonbit
// 检查是否为闰月
let lunar_month = LunarMonth::from_ym(2024, 2).unwrap()
if lunar_month.is_leap() {
  println("闰月")
}

// 闰二月
let leap_month = LunarMonth::from_leap_ym(2024, 2).unwrap()
```

## 公历 ↔ 儒略日

儒略日是天文计算的基础，所有历法转换都通过儒略日进行。

### 公历转儒略日
```moonbit
let solar_day = SolarDay::from_ymd(2024, 1, 1).unwrap()
let julian_day = JulianDay::from_solar_day(solar_day)
println(julian_day.to_string())
```

### 儒略日转公历
```moonbit
let jd = JulianDay::from_julian_day(2460321.5)  // 2024-01-01
let solar_day = jd.to_solar_day()
```

### 儒略日常量
```moonbit
// J2000 历元：2000年1月1日 12:00:00 UTC
pub const J2000: Int = 2451545
```

## 节气计算

### 获取节气
```moonbit
// 根据年份和索引获取节气（0-23）
let term = SolarTerm::from_index(2024, 3)  // 立春
println(term.to_string())  // 立春

// 根据名称获取节气
let term = SolarTerm::from_name(2024, "清明").unwrap()
```

### 节气时刻
```moonbit
let term = SolarTerm::from_name(2024, "立春").unwrap()
let jd = term.get_julian_day()  // 节气精确时刻（儒略日）
let solar_time = jd.get_solar_time()  // 对应的公历时刻
```

### 当前节气
```moonbit
let solar_day = SolarDay::from_ymd(2024, 2, 4).unwrap()
let current_term = SolarTerm::get_current_term(solar_day)
println(current_term.to_string())  // 立春
```

## 伊斯兰历

### 伊斯兰历转换
```moonbit
import tyme

// 公历转伊斯兰历
let solar_day = SolarDay::from_ymd(2024, 1, 1).unwrap()
let hijri_day = HijriDay::from_solar_day(solar_day).unwrap()
println(hijri_day.to_string())

// 伊斯兰历转公历
let hijri_year = HijriYear::from_year(1445).unwrap()
let hijri_month = HijriMonth::from_ym(1445, 7).unwrap()  // 赖买丹月
let hijri_day = HijriDay::from_hdy(hijri_month, 1).unwrap()
let solar_day = hijri_day.to_solar_day().unwrap()
```

## 注意事项

1. **年份范围**：公历支持 1-9999 年，农历支持 -1 到 9999 年
2. **农历闰月**：闰月的月份号为负数或特殊标记
3. **节气时刻**：节气时刻精确到秒，用于八字计算
4. **真太阳时**：八字计算需要考虑真太阳时修正
5. **伊斯兰历**：伊斯兰历为纯阴历，与公历没有固定对应关系
