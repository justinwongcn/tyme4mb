# 八字计算工作流

八字（四柱）是中国命理学的核心，根据出生年月日时的干支来表示。

## 八字结构

```
        年柱      月柱      日柱      时柱
       ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
       │ 甲子 │ │ 乙丑 │ │ 丙寅 │ │ 丁卯 │
       └──────┘ └──────┘ └──────┘ └──────┘
         ↑          ↑          ↑          ↑
       天干       天干       天干       天干
       地支       地支       地支       地支
```

## 计算流程

### 1. 输入准备
```moonbit
// 公历出生时间
let solar_time = SolarTime::from_ymdhms(1986, 5, 29, 13, 0, 0).unwrap()
let solar_day = SolarDay::from_ymd(1986, 5, 29).unwrap()
```

### 2. 转换为农历
```moonbit
// 公历转农历
let solar_day = SolarDay::from_ymd(2024, 1, 15).unwrap()
let lunar_day = solar_day.get_lunar_day()
let solar_time = SolarTime::from_ymdhms(2024, 1, 15, 10, 30, 0).unwrap()
let lunar_hour = solar_time.get_lunar_hour().unwrap()
```

### 3. 获取节气信息
```moonbit
// 获取当前所在的节气
let current_term = solar_day.get_term()
let next_term = current_term.next(1)
```

### 4. 计算八字
```moonbit
// 通过 SolarTime 直接获取八字（推荐方式）
let solar_time = SolarTime::from_ymdhms(1986, 5, 29, 13, 0, 0).unwrap()
let eight_char = solar_time.get_lunar_hour()?.get_eight_char()

// 或使用全局提供者（旧方式）
// let eight_char = eight_char_provider.get_eight_char(lunar_hour)
```

## 真太阳时支持（v0.2.2 新增）

八字计算支持真太阳时修正，适用于精确排盘。

### 真太阳时计算
```moonbit
// 通过 SolarTime 获取真太阳时
let solar_time = SolarTime::from_ymdhms(1986, 5, 29, 13, 0, 0).unwrap()
let true_solar_time = solar_time.to_true_solar_time(116.39)  // 北京经度

// 使用真太阳时计算八字
let eight_char = true_solar_time.get_lunar_hour()?.get_eight_char()
```

### 童限双轨模式
```moonbit
// 平太阳时模式
let child_limit1 = ChildLimit::from_solar_time(birth_time, gender)

// 真太阳时模式（需传入出生地经度）
let child_limit2 = ChildLimit::from_true_solar_time(birth_time, gender, 116.39)
```

**设计要点**：四柱按真太阳时读数计算，节令判断与起运时间差仍按钟表绝对时刻，避免真太阳时读数与钟表系节气时刻混用导致的时间差扭曲。

## 月柱推算规则

月柱根据地干五虎遁规则推算：
```
甲己之年丙作首，乙庚丙作初，
丙辛从戊起，丁壬壬位顺行流，
若问戊癸何处起，甲寅之上好追求。
```

## 时柱推算规则

时柱根据地干五鼠遁规则推算：
```
甲己还加甲，乙庚丙作初，
丙辛从戊起，丁壬庚子居，
戊癸何方发，壬子是真途。
```

## 常见问题

### Q: 如何判断节气换柱？
A: 检查出生时间是否在节气时刻之后，如果在则月柱用下一个节气的干支。

### Q: 真太阳时如何计算？
A: 真太阳时 = 钟表时间 + 经度差修正 + 均时差。均时差通过天文公式计算，考虑地球公转轨道偏心和黄赤交角。
