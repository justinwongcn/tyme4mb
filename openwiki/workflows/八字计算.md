# 八字计算工作流

八字（四柱）是中国命理学的核心，根据出生年月日时的干支来表示。

## 八字结构

```
        年柱      月柱      日柱      时柱
       ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
       │ 甲子 │ │ 乙丑 │ │ 丙寅 │ │ 丁卯 │
       └──────┘ └──────┘ └──────┘ └──────┘
         ↑          ↑          ↑          ↑
       天干       天干       天干       天干
       地支       地支       地支       地支
```

### 月柱推算规则
月柱根据地干五虎遁规则推算：
```
甲己之年丙作首，乙庚之岁戊为头，
丙辛必定寻庚起，丁壬壬位顺行流，
若问戊癸何处起，甲寅之上好追求。
```

### 时柱推算规则
时柱根据地干五鼠遁规则推算：
```
甲己还加甲，乙庚丙作初，
丙辛从戊起，丁壬庚子居，
戊癸何方发，壬子是真途。
```

## 真太阳时修正

八字计算需要考虑真太阳时，而非钟表时间。

### 修正公式
```
真太阳时 = 钟表时间 + 经度差修正 + 均时差
```

## 常见问题

### Q: 如何判断节气换柱？
A: 检查出生时间是否在节气时刻之后，如果在则月柱用下一个节气的干支。

### Q: 子时如何划分？
A: 子时分为早子时（23:00-00:00）和晚子时（00:00-01:00），传统上有不同处理方式。

### Q: 真太阳时如何获取？
A: 需要知道出生地的经度，然后根据公式计算。可以使用在线真太阳时转换工具。
